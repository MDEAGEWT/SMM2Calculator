## 언어

- 화면 언어는 언어 설정에서 중국어, 영어, 스페인어, 한국어 중에 고를 수 있습니다. 영어와 한국어는 게임의 공식 명칭을 따릅니다 (블랙뻐끔, 가시 지형, 쓱싹쓱싹, 반벽 지형, 딱딱블록 등).
- 명령어는 화면 언어와 상관없이 한국어, 중국어, 영어 어느 것으로 입력해도 됩니다. 명령 버튼에는 화면 언어 이름이 표시됩니다. 예: `우걷기1 뒤웅크리기1 우대시51 앞웅크리기1 가속우점프16`. 전체 목록은 `Languages/Korean.ini`의 `[COMMANDS]`에 있습니다.

## 쓱싹쓱싹(그라인더)

장애물 목록에 추가했습니다. 3x3 블록 크기이고, 데미지 판정은 중심에서 반지름 16px인 원입니다. 공식 수치가 없어 추정값을 썼습니다. J18-0TG-33G 클리어 영상에서 웅크리기 점프 판정이 그라인더 중심에서 약 18.3px 떨어진 곳을 지나가므로, 실제 반지름은 그보다 작습니다.

## 맵 가져오기

`코스 ID`에 코스 ID(`J18-0TG-33G`)나 mm2list 주소를 넣고 `맵 가져오기`를 누릅니다.

- mm2list(`https://mm2list.cyzon.us/cached-view/<코스 ID>`)에는 코스 데이터가 없고 toost로 그린 맵 이미지만 있습니다. 그래서 이 이미지를 게임 텍스처와 픽셀 단위로 비교해 땅·블록·토관과 가시 지형·뻐끔플라워·블랙뻐끔·쓱싹쓱싹을 찾습니다.
- 칸을 비워 두고 누르면 게임 세이브의 코스 파일(`course_data_XXX.bcd`, 암호화된 파일 그대로)이나 맵 PNG를 열 수 있습니다.
- `맵 X`/`맵 Y`는 캔버스 왼쪽 아래에 올 블록 좌표입니다. `서브 에리어`를 체크하면 서브 에리어를 가져옵니다.
- 계산기의 땅(`땅 폭`/`땅 높이`)은 캔버스 왼쪽 끝 기둥 높이로 자동 설정됩니다. 지형은 배경 그림으로만 표시되고, 판정은 장애물에만 적용됩니다.
- SMB1·SMB3·SMW만 지원합니다. NSMBU·3D World는 텍스처가 없어 가져올 수 없습니다.
